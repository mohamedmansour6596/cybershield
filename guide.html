Security guide

How to spot a phishing link

Phishing tricks people into entering passwords or payment details on a fake page. These are the signs CyberShield looks for, and what you should do.

1. No HTTPS

HTTPS encrypts the connection. A login page on plain http:// is a red flag. Note that HTTPS alone does not prove a site is honest, because attackers can get free certificates too.

2. IP address instead of a domain

A link like http://185.23.4.9/login has no brand name. Real services use domain names.

3. Urgent keywords

Words such as login, verify, update, suspend and secure are used to create panic: "Your account will be closed!".

4. Fake or stacked subdomains

In paypal.com.evil-site.xyz the real domain is evil-site.xyz. Always read the domain from right to left, before the first single slash.

5. The @ trick

In https://bank.com@evil.com the browser goes to evil.com. Everything before @ is ignored.

6. URL shorteners

Short links such as bit.ly hide the destination. Use a link expander or ask the sender for the full link.

7. Look-alike characters (Punycode)

Domains that start with xn-- can imitate brands using characters that look the same, like Cyrillic "а" instead of Latin "a".

8. Risky TLDs and unusual ports

Cheap endings like .xyz, .top or .tk are abused often. Ports such as :8080 are rare on real login pages.

What to do when you get a suspicious link

  1. Do not click. Long-press or right-click and copy the link instead.
  2. Check the sender through another channel (call them, or open the official app).
  3. Analyse the link in the CyberShield scanner.
  4. Never enter passwords or OTP codes from a link you received. Type the official address yourself.
  5. Enable two-factor authentication so a stolen password is not enough.
  6. Report the message (WhatsApp / email provider) and delete it.

About this project's own security

CyberShield never connects to the links you submit (prevents SSRF), validates all input, limits requests per client, uses CSRF tokens, escapes all output, uses parameterised SQL and sends strict security headers including a Content-Security-Policy.
